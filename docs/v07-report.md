# 知微 SenseMind v0.7 第一阶段验收

基准 `d172dc0`；分支 `codex/ppg-training`。本阶段不合并 main，不声称已完成 ESP32 实物联调或医疗监测验证。

## 运行方式

继续使用同一 `/v1/telemetry` 接口。每条遥测记录 `data_mode`、`source`、可选 dataset / participant_id，JSON 持久化沿用现有表，不迁移或破坏数据库。

- **Replay Mode**：`source=simulator`，科研回放同时记录 `dataset=ppg-dalia`。省略 data_mode 时由来源推导为 replay；显式误标 live 返回 422。
- **Live Mode**：为未来 ESP32 保留 `source=esp32,data_mode=live`；也兼容原 STM32/ring。来源是调用者声明，不等于系统已经证明硬件在线。ESP32 与原硬件一样，默认关闭真实生理告警规则，需原有显式实验开关才能启用。
- ML 输入域限制保留：E4 数据仅用于 PPG 模型；PAMAP2 的活动模型不直接应用于 ESP32 或 E4。模型已加载不等于任意硬件输入都可推理。
- `/v1/runtime/status` 返回三模型状态、DeepSeek 配置状态、模式与硬件验收说明。配置成功不会被显示为外部网络调用成功。

控制台保留原事件证据链、通知、人工确认入口，新增模式、数据来源、PPG 心率、HR 一致性代理、模型窗口时间、降级原因与三模型状态。WebSocket 指示明确称“控制台连接”，不会暗示真实硬件实时采集。已在真实浏览器打开并检查最终回放页面与调查详情；没有代替人工确认事件。

## 真实 DeepSeek 联调

见 [脱敏调用及调查证据](v07-deepseek.json)。使用现有 `.env` 配置与 `deepseek-flash`，实际发送到 DeepSeek 官方接口；未使用模拟传输冒充真实联调。

测试数据完全由脚本生成：一个虚构设备、正常历史记录、真实已训练 PPG 权重对程序生成的 1.2 Hz 正弦波和固定种子 ACC 的推理记录，以及 3 条虚构的高心率规则输入。遥测的 75/130 bpm 是虚构测试值；模型工具里的 HR 则由真实训练权重对合成波形推理产生，不能当成个人测量或准确率证据。没有向外部发送 PPG-DaLiA 原始信号、ECG 标签或真实用户健康记录。

实际工具调用包含 `summarize_status`、`get_model_outputs`、`get_history`。模板从最新记录解释 HR/质量，仍限制为研究事实，不能生成疾病诊断或发作概率。真实异常候选由原规则引擎触发异步调查；AI 完成分析，证据/工具参数/摘要/不确定性保存在脱敏记录中，人工确认仍为 false。

网络中断和 API 超时的新增自动测试确认会返回明确错误码并降级到本地查询；原鉴权、余额、限流、提供方错误处理保留。调查失败仍生成本地确定性证据摘要，不把未成功的调用标成 AI 成功。

## 78 窗质量审计

见 [逐窗离线数据](v07-quality.json)。复现 T5 的 S13/S14/S15 静坐、步行各 20 秒，共 78 个成熟尾随 8 秒窗口。回放起点不一定落在官方 2 秒标签网格上，因此离线参考用同一时间范围内纠正后的 700 Hz ECG R 峰重算平均瞬时 HR，未粗暴四舍五入套用邻近标签。ECG 仅存在于独立离线脚本，绝不发送到推理 API 或 DeepSeek。

| 指标 | 结果 |
| --- | --- |
| 质量阈值 | 保持 0.7，未为提升显示率降低 |
| HR 输出 | 32 / 78 = **41.03%** |
| 120 个一秒遥测时隙中有效 HR | 32 / 120 = **26.67%**（含预热） |
| 隐藏 HR | 46 / 78，全部原因为 low_proxy_reliability |
| 隐藏窗口可靠性范围 | 0.3643–0.6884 |
| 保留窗口可靠性范围 | 0.7077–0.9861 |
| 未过滤回归 HR 对 ECG 的 MAE | 4.92 bpm |
| 保留窗口 MAE | 1.91 bpm |
| 隐藏窗口的未过滤 HR MAE | 7.01 bpm |
| 隐藏窗口中回归 HR 误差 ≤10 bpm | **34 / 46** |
| 隐藏窗口中原启发式 HR 代理标签为可靠 | **40 / 46** |
| 保留窗口中回归 HR 误差 >10 bpm | 0 / 32 |

这说明过滤在这批短片上降低了输出误差，但牺牲了很多本来与 ECG 接近的 HR 估计：全部 66 个误差 ≤10 bpm 的回归窗口中，34 个被隐藏，比例 51.52%。这属于明显的过度隐藏迹象；不能进一步声称这些波形都是“正常信号”，因为没有独立人工 SQI 标注。

质量标签定义针对的是既有启发式 PPG_HR 与 ECG 的一致性，不能直接等同于新 HR 回归器的可信度。当前门控未校准，未来需独立验证集、独立质量标签或专门的回归误差置信度模型；本阶段不使用这批独立测试受试者调阈值。

最长成熟窗口连续隐藏为 13 个一秒更新时隙；首末更新时间跨度为 12 秒。计入前 7 秒预热，三个步行片段均连续 20 秒没有 HR 输出。六段来自不同受试者/活动，不能拼成一个连续长缺测时间。相邻窗口高度重叠，不能当成 78 个独立统计样本。

## 稳定性验收

见 [稳定性原始结果](v07-stability.json)。连续真实时间 **600 秒**；含数据加载总耗时 **603.51 秒**。通过真实 loopback HTTP / uvicorn / SQLite 完成 600 次遥测、593 次完整窗推理；数据库独立复核持久化数量一致，全部来源为 replay/simulator；HTTP 错误 0，最慢请求 **0.594 秒**。所有三模型在结束时仍 available。源代码 SHA-256 快照在运行开始后保存并于结束时核对未变化。初步运行在发现单位问题后由本 agent 中断，其结果不计入本次验收；以上是修复后重新完整运行的结果。

回放用 S13 的连续 working 活动片段。科研历史时间戳映射到近过去；早期窗口显示 stale 是历史回放语义，不等于服务断网。稳定性测试关闭外部模型，避免 10 分钟科研回放事件不必要地触发外部请求；真实 DeepSeek 工具和调查用前述独立安全夹具验收。十分钟通过只说明此次运行的稳定性，不代表长期可用率。

## Warnings 与兼容性

1. 原 NumPy `invalid value encountered in divide` 来自常量加速度轴的相关系数。新增零方差保护返回 0，与原特征最终 `nan_to_num` 的结果一致；不是隐藏 warning。新增测试以 RuntimeWarning 为错误验证该路径。模型权重没有修改或重训，六项原 SHA-256 校验通过。
2. 剩余 Starlette/httpx 弃用：本机 FastAPI 0.162.0 / Starlette 1.10.0 / httpx 0.28.1。Starlette 测试客户端优先寻找 httpx2，未安装时走旧 httpx 兼容路径并警告。此为测试客户端依赖迁移提示；本阶段不改现有训练环境、不用过滤器屏蔽。应在独立环境验证 httpx2 迁移后再升级锁文件。

另修复 T5 遗留的遥测单位方向错误：遥测契约约定 **g**；PPG 摘要保持 E4 g，PAMAP2 摘要由 m/s² 除以 9.80665 后送规则引擎。机器学习输入维持原训练单位。对照真实页面与新增测试，常量重力不再因错用单位触发运动规则；原规则阈值未更改。

完整自动测试：**127 passed，1 warning**。包含现有 Agent、API、数据库、告警、人工确认、回放回归，以及模式冲突、未来 ESP32 默认禁用生理规则、网络/超时降级、常量相关性和回放单位测试。

## 可复现操作

在项目根目录使用原 `.venv`，数据和产物依照 [T4/T5 恢复说明](t4-t5-report.md) 恢复。不要提交 .env、数据库、数据和训练产物。

```bash
.venv/bin/python scripts/verify_artifacts.py
.venv/bin/python -m pytest -q
# 离线 ECG 对照，无外部模型调用
.venv/bin/python scripts/audit_v07_quality.py
# 使用已有 .env 的真实 API；只创建虚构夹具，会消费 API 额度
.venv/bin/python scripts/verify_v07_deepseek.py
# 真实时间 600 秒，临时独立端口与本地 SQLite；结束后只关闭自身服务
.venv/bin/python -u scripts/verify_v07_stability.py
```

本地演示控制台（科研回放保持本地分析）：

```bash
# 终端 1，先确保 .runtime/v07 存在
mkdir -p .runtime/v07
GUARDIAN_DB=.runtime/v07/demo.db GUARDIAN_LLM_MODE=off .venv/bin/python -m uvicorn guardian.main:app --host 127.0.0.1 --port 8000
# 打开 http://127.0.0.1:8000/console
# 终端 2：PPG 必须显式选择受试者；速度 1 = 真实时间
.venv/bin/python scripts/replay_dataset.py --url http://127.0.0.1:8000 --dataset ppg --subject S13 --activity 8 --seconds 600 --speed 1
```

在只接收虚构测试数据的独立演示数据库中，可不设置 `GUARDIAN_LLM_MODE=off`，应用即读取现有 `.env` 接入真实 DeepSeek。实际工具调用才证明连通，配置状态不代表连通。未来真硬件或个人数据接入前，需要另行明确外发数据范围。

## 已知限制

ESP32 仅有接口预留和自动化契约测试，没有实物验收。门控保守、受试者/活动分布差异、PAMAP2 walking 弱项继续存在。数据来源字段是声明信息，不是硬件身份认证。
研究回放通常没有 SpO2，原质量规则可能创建缺测事件；本阶段保留规则与人工确认机制，不把这些候选事件解释为疾病。
调查报告是事件触发时快照，预热阶段可能没有模型证据；设备卡与模型查询显示其后的新窗口，不能把两者混为同一时点。
